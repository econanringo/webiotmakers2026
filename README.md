# CHIRIMEN リモート操作

Raspberry Pi（CHIRIMEN）に接続した **ファン・音楽プレイヤー・サーボ・LED** を、1つのプログラムで動かします。  
スマホのブラウザから、インターネット経由でも操作できます。

スマホと Raspberry Pi が同じ Wi-Fi である必要はありません。どちらも Chirimen の WebSocket リレーに接続します。

## できること

| 機能 | 自動動作 | スマホからの操作 |
| --- | --- | --- |
| ファン | 27℃以上で ON、25℃以下で OFF | 自動 / 強制 ON / 強制 OFF |
| LED | 50 lx 未満でハロウィン点灯。左右スイッチでウインカー | 自動 / ハロウィン / 左ウインカー / 右ウインカー / 消灯 |
| 音楽 | なし | 曲番号 1〜6 を再生（Pi のキーボードでも可） |
| サーボ | UNLOCK 中にボタンまたは照度で動く | UNLOCK / LOCK / サーボを動かす |

サーボのボタン操作と照度トリガーは、**UNLOCK のときだけ**有効です。スマホの「サーボを動かす」はロック中でも動きます。

## 必要なもの

- CHIRIMEN 環境が入った Raspberry Pi
- インターネット接続（リレー通信と操作画面の読み込みに使います）
- 接続機器
  - ファン用リレー（GPIO 17）
  - 温湿度センサ SHT30（I2C `0x44`）
  - 照度センサ BH1750（I2C `0x23`）
  - サーボ用 PCA9685（I2C `0x40`、チャネル 0）
  - ボタン（GPIO 5、押すと Low）
  - 出力（GPIO 26）
  - DFPlayer Mini（シリアル `/dev/serial0`、曲 1〜6）
  - 左 NeoPixel（I2C ポート 1、アドレス `0x41`、144 LED）
  - 右 NeoPixel（I2C ポート 3、アドレス `0x41`、144 LED）
  - 左ウインカー スイッチ（GPIO 24、押すと High）
  - 右ウインカー スイッチ（GPIO 25、押すと High）

## 使い方（最短）

Raspberry Pi のプロジェクトフォルダで、次を実行します。

### 1. 機器側を起動する

未導入なら、先に WebSocket 用パッケージを入れます。

```bash
npm install websocket
```

本体を起動します。

```bash
node main.js
```

ターミナルに `web socketリレーサービスに接続しました` と出れば準備完了です。

### 2. 操作画面を公開する

別のターミナルで、同じフォルダから HTTP サーバを起動します。

```bash
python3 -m http.server 8080
```

HTML を `file://` で直接開くと接続に失敗しやすいので、必ず HTTP 経由で開いてください。

### 3. スマホで操作する

1. スマホのブラウザで `http://<Raspberry PiのIPアドレス>:8080/` を開く
2. 画面上が **接続済み** になるのを待つ
3. ボタンを押してファン・LED・音楽・サーボを操作する

Pi の IP アドレスがわからないときは、Pi 側で `hostname -I` を実行します。

操作画面さえ開けば、その後の通信は Chirimen リレー経由です。モバイル通信のスマホからでも操作できます。

## 画面の見方

画面上部が **接続済み** になってから操作してください。**接続中...** のままなら、Pi 側の `node main.js` が動いているか、インターネット接続を確認してください。

### ファン

- **自動**: 温度で ON/OFF（初期状態。27℃以上で ON、25℃以下で OFF）
- **ON**: 温度に関係なく回し続ける
- **OFF**: 温度に関係なく止める

温度・湿度・ファン状態（ON/OFF と自動/手動）が画面に表示されます。

### LED

- **自動**: 暗いとき（50 lx 未満）ハロウィン点灯。GPIO 24/25 のスイッチで左右ウインカー（初期状態）
- **ハロウィン**: 明るさに関係なく、オレンジ×紫のグラデーション
- **左ウインカー** / **右ウインカー**: 明るさに関係なく、指定側だけ流れるウインカー。反対側はハロウィン点灯
- **消灯**: 左右とも消す

自動のときは、明るい場所（50 lx 以上）では消灯します。

### 音楽

1〜6 のボタンで、対応する曲を再生します。  
Raspberry Pi のターミナルでも、`1`〜`6` を入力して Enter で再生できます。

### サーボ

- **UNLOCK**: ボタンと照度トリガーを有効にする
- **LOCK**: ボタンと照度トリガーを無効にする
- **サーボを動かす**: 今すぐ1回動かす

照度が 10 lx 以上の状態が 5 秒続くと、UNLOCK 中かつ「次が起動（ON）」のタイミングでサーボが動きます。

終了するときは、`node main.js` を動かしているターミナルで `Ctrl+C` を押します。

## チャンネル名

スマホと Raspberry Pi は、同じチャンネル名で通信します。

```
webiotmakers2026-team-a
```

ほかの人と混線したときは、次の **2箇所を同じ文字列** に変えてください。

- `main.js` の `CHANNEL_NAME`
- `index.html` の `CHANNEL_NAME`

公開リレーには認証がないため、チャンネル名が分かれば第三者も送受信できます。本番用途には向きません。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `main.js` | **普段使う本体。** ファン・LED・音楽・サーボとリモート操作をまとめたプログラム |
| `index.html` | スマホ／PC 用の操作画面 |
| `RelayServer.js` | Chirimen WebSocket リレー用ライブラリ |
| `fan.js` | ファン単体の参考コード（実行しなくてよい） |
| `music.js` | 音楽単体の参考コード（実行しなくてよい） |
| `servo.js` | サーボ単体の参考コード（実行しなくてよい） |

普段は `main.js` と `index.html` だけ使います。`fan.js` / `music.js` / `servo.js` は部品ごとの元コードです。

## うまく動かないとき

- **接続済みにならない**  
  `node main.js` が起動しているか、Pi とスマホのインターネットを確認してください。操作画面は HTTP（`http://...:8080/`）で開いてください。
- **ファンが温度で動かない**  
  画面のファンが「ON / ON」や「OFF / OFF」なら手動固定です。「自動」を押してください。
- **ボタンや明るさでサーボが動かない**  
  画面のロックが **UNLOCK** になっているか確認してください。
- **曲が鳴らない**  
  DFPlayer の配線、`/dev/serial0`、SD カードの曲番号 1〜6 を確認してください。
- **LED が点かない**  
  画面の LED が「自動」なら、照度が 50 lx 未満か確認してください。I2C ポート 1（左）とポート 3（右）、アドレス `0x41` も確認してください。
- **`websocket` が見つからない**  
  `npm install websocket` を実行してください。
